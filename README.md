# WA

Redirección al WhatsApp de Grabarte. **Este es el único lugar donde vive el número.**

El QR grabado/impreso codifica `HTTPS://JESOFTBUILDING.GITHUB.IO/WA` (todo en mayúsculas a propósito: el QR queda de 25 módulos en vez de 41, y el nombre del repo tiene que ser `WA` en mayúsculas porque GitHub Pages distingue mayúsculas en la ruta).

Para cambiar el número: editar la URL en `index.html` (meta refresh, variable DESTINO y el botón) y pushear. No renombrar este repo ni la organización.
